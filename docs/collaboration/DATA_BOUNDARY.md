# גבול מידע והרשאות לשיתוף

מטרת מסלול זה היא שיתוף תשתית כללית ותוכן ציבורי/בדיוני בטוח. הוא אינו מעניק הרשאה לשיתוף כל המאגר עם ספק AI נוסף.

- במועד ההקמה המאגר דווח על ידי GitHub כציבורי. קיימות בו 5,000 רשומות מיובאות שלא עברו ביקורת תוכן; ציבוריות המאגר אינה הוכחת בטיחות או הרשאה להעברה נוספת.
- לפני הרחבת גישה, בעל המאגר בודק את הנראות, ההרשאות, ההיסטוריה והתוכן, ומוודא שאינם כוללים מידע ארגוני לא מורשה או מידע אישי. עד אז מוסרים לעובד רק את הפרומפט, מסמכי השיתוף וקבצים שאושרו לשיתוף בנפרד. ענף בתוך אותו מאגר אינו מנגנון בקרת גישה.
- אין לשתף PAT, סודות, מפתחות, חשבונות, או פרטי התחברות של אחרים. השתמשו בהרשאה מינימלית דרך חשבון המשתמש ובאישור בעל המאגר. אם אין אפשרות להגביל הרשאות באופן מתאים, העובד מחזיר קובץ והבעלים מבצע את הקליטה.
- אין להעביר `data/`, `metadata/`, `exports/`, `archive/`, טיוטות היסטוריות או דוגמאות מהייבוא לספק חיצוני לפני בדיקת תוכן והרשאת שיתוף.
- תוכן חדש: מידע ציבורי כללי, לימודי, היסטורי או תרחישים אזרחיים/ארגוניים בדיוניים שאינם מבצעיים. ללא פרטי נשק מעשיים, תכנון או הפעלה, טקטיקה, ניצול חולשות, מידע מסווג אמיתי או מזהים אישיים.
- אין לקבוע רמת סיווג אמיתית של מסמך רגיש. ארבע התוויות הן סימולציה של רגישות כללית.
- אם נתקלתם במידע חריג, אל תעתיקו אותו למסרים, לוגים או תוצרי ספק; עצרו את הטיפול באותו פריט ודווחו רק על נתיבו לבעל המאגר.

כללי הספק, מדיניות הארגון וההרשאות חלים בנוסף למסמך זה. אין לעקוף אותם.
