## סתירות, הבדלי גרסאות וחסמים שנותרו

1. **מכסות:** `label_length_quota: passed` ההיסטורי מתייחס לתכנון הישן. בפועל בכל העותקים `[6,50,44,25]` לכל תווית, ואילו המנה הבאה לפי `progress.json` דורשת `[7,50,43,25]`. אף עותק אינו תואם למכסת המנה הבאה כעת. אין להחיל מכסה זו אוטומטית על 0007–0009 העתידיות; יש לחשב מחדש במועד קליטה לאחר שינוי ההתקדמות.
2. **מקור E5 ב־0006 — הבירור הושלם:** בקוד `semantic_scan` ההיסטורי, `indexed_records` הוא מספר הווקטורים של `prior + rows`, ו־`scanned_records` הוא מספר המועמדים. לכן ייחוס 0004/2,000 יחד עם 500 מועמדים ו־2,500 באינדקס עקביים זה עם זה; התיאור הקודם כפער מספרי תוקן. זו פרשנות לפי הקוד והמטא־דאטה, ולא שחזור הרצה. אין כאן ראיה לסריקה מול 2,500 רשומות ייצור: ה־baseline מתעד ייחוס ל־0004 ומקור Chat לפני תיקוני Work. ראו [קוד הסריקה בגרסת שמירת דוח Work](https://github.com/gal-dd/SentinelAI-DB/blob/7321940354d8bb102f44493bd32a7c4cc9331032/sentinel_dataset/semantic.py). חסם הסריקה והכרעת הזוגות בעותק המעודכן נשאר פתוח.
3. **SHA ב־Windows:** ההשוואה הראשונית לבתי הקבצים המקומיים נכשלה בשני קובצי 0006. `core.autocrlf=true` ו־`git ls-files --eol` הראו Git עם LF ו־checkout עם CRLF. SHA-256 של בתי Git ושל עותק מקומי לאחר המרת CRLF ל־LF תואם בדיוק לדוחות: Chat `708f957d66d826a3ba535b1b4adcc48ad2b1c5d9aeb651f3184f6af350ca48e6`; Work `aa54df5dcbd2da9857c13dae5f571ba2cabf428573712076fb63b6c3d3493df7`. אין ראיה לשינוי תוכן; אין לטעון שה־hash הגולמי של checkout תואם. לא שונו קבצים או הגדרות Git כדי ליישר hashes.
4. **עקיבות דוחות — מיפוי הגרסאות הושלם:** אין ב־0007–0009 hash מועמדים מוצהר בדוחות המקור. במפת העקיבות החדשה נרשמו Git blob וקומיט שמירה לכל דוח, ולצדם גרסת המועמדים באותו קומיט. בכל 17 קובצי הראיות העדכניים, גרסת המועמדים בעת שמירת הקובץ זהה לגרסה הנוכחית של אותה תיקייה. בכך נסגר פער זיהוי הגרסאות ב־Git בלי להוסיף בדיעבד הצהרת hash לדוח הישן. זהות גרסאות שנשמרו אינה הוכחה שהבדיקה אכן הורצה על אותן רשומות, ואינה אישור לתוכן; ההבחנה בין baseline של Chat לבין תוצאות Work נותרת בתוקף.
5. **תוכן וקליטה:** נותרו ביקורת עצמאית של תוויות ותחומים, השלמת ביקורת 0006 ותיקוניה, טיפול עריכתי ב־0007–0009, בדיקות סמנטיות והכרעות זוגות, ואימות מול מצב הייצור הרלוונטי. אלה חסמי המנות; טיפול תוכן ופרסום אינם חלק מהמשימה הנוכחית. אין לפתוח מחדש את מעמד 0001–0005 כדי לתעד אותם.

הסתירות במסמכי הניהול הוסרו: ההוראות הישנות להסדרת מנוע כתנאי פתיחה הוחלפו בהפניה להיקף שכבר אומת; הופרדו בדיקות תוכנה, שלמות מבנית ואיכות תוכן. בעדכון ההמשך תוקנה פרשנות ספירת E5 ונוספה עקיבות גרסאות; מגבלות הראיות שנותרו מפורשות לעיל. דוחות המקור לא שונו בדיעבד.
